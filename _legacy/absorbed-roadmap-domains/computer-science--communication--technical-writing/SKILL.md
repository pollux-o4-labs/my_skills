# Apply technical writing principles

Consider the principles broadly. Select and combine the approaches that best fit the task, including perspectives that may reveal blind spots or enable useful reframing.

Audience Analysis, Task Orientation, Information Architecture, Progressive Disclosure, Plain Language, Documentation as Code, Single Source of Truth, Versioning, Examples, Technical Accuracy, Documentation Usability.

# Scope

- Developer documentation and technical communication
- API references, tutorials, runbooks, onboarding, and operational guides
