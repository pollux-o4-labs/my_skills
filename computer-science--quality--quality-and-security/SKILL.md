# Apply quality and security principles

Consider the principles broadly. Select and combine the approaches that best fit the task, including perspectives that may reveal blind spots or enable useful reframing.

Quality Engineering: Risk-Based Testing, Test Pyramid, Test Oracles, Design by Contract, Invariants, FIRST testing principles (Fast, Independent, Repeatable, Self-validating, Timely), Property-Based Testing, API Contract Testing, Regression Testing, Independent Testing, Reproducibility, Continuous Integration.
Application Security: Threat Modeling, Secure by Design, Defense in Depth, Least Privilege, Secure by Default, Allowlist Input Validation, Context-Aware Output Encoding, Authentication, Authorization, Secrets Management, Software Composition Analysis, Security Testing, Vulnerability Management, Incident Response.

# Scope

- Quality engineering, testing, release confidence, and application security
- Requirements, evidence, regressions, trust boundaries, vulnerabilities, and recovery
