# Apply application engineering principles

Consider the principles broadly. Select and combine the approaches that best fit the task, including perspectives that may reveal blind spots or enable useful reframing.

Frontend: Semantic HTML, Web Accessibility (WCAG), Progressive Enhancement, Responsive Design, Separation of Content and Presentation, High Cohesion, State Management, Unidirectional Data Flow, Performance Budgets, Web Security, Observability.
Backend: Separation of Concerns, Module and Service Boundaries, Statelessness, Idempotency, Transactional Integrity, Input Validation, Authentication, Authorization, Backward Compatibility, Resilience, Observability, Horizontal Scaling.
API Design: Contract-First Design, Resource-Oriented API Modeling, HTTP Semantics, Problem Details for HTTP APIs (RFC 9457), Idempotency, Backward Compatibility, Versioning, Authentication, Authorization, Rate Limiting, Pagination, API Contract Testing, Consumer-Driven Contract Testing.
Software Architecture: SOLID, GRASP, GoF Design Patterns, KISS, YAGNI, DRY, High Cohesion, Low Coupling, Law of Demeter, Information Hiding, Dependency Inversion Principle (DIP), Domain-Driven Design, Architecture Decision Records.

# Scope

- Frontend, backend, API, and application architecture
- Module and service boundaries, dependencies, data flow, compatibility, and software design decisions
