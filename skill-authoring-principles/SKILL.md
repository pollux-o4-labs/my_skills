# Apply skill-authoring principles

Use `templates/domain-principles-template/SKILL.md` as the source of truth when creating or revising a skill.

Apply the template's principles together with the authoring principles below.

Avoid Premature Convergence: treat principles as lenses to select and combine for the task, not as a fixed checklist or universal solution.
Preserve User Intent: when the user explicitly requests a single case, fixed format, or narrow lens, honor that scope without broadening it unnecessarily.

Progressive Disclosure, Single Responsibility Principle, DRY, YAGNI, Single Source of Truth, Backward Compatibility, Interface Segregation Principle.

# Scope

- Skill creation and refactoring
- Repository skill bootstrap
- Lesson promotion into reusable skills
