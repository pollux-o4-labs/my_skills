# Apply computing, data, and intelligence principles

Consider the principles broadly. Select and combine the approaches that best fit the task, including perspectives that may reveal blind spots or enable useful reframing.

Computing Fundamentals: Abstraction, Modularity, Separation of Concerns, Information Hiding, Data Representation, State Management, Determinism, Concurrency Correctness, Resource Ownership, Failure Isolation, Complexity Analysis.
Data Structures and Algorithms: Problem Decomposition, Abstract Data Types, Invariants, Correctness Proofs, Asymptotic Analysis, Time–Space Trade-off, Recursion, Iteration, Graph Modeling, Locality of Reference, Amortized Analysis.
Database Engineering: Data Modeling, Normalization, Constraints, ACID, Transaction Isolation, Indexing, Query Planning, Schema Evolution, Database Migrations, Replication, Backup and Recovery, Consistency Models.
Product Analytics: Event Taxonomy, Event Instrumentation, Funnel Analysis, Cohort Analysis, Retention Analysis, North Star Metric, Guardrail Metrics, Experiment Design, Causal Inference, Data Quality, Metric Governance.
AI and Machine Learning Engineering: Data Quality, ML Data Leakage Controls, Baseline Evaluation, Evaluation Design, Reproducibility, Model Versioning, Distribution Shift, Model and Data Monitoring, Human Oversight, Privacy, Safety, Cost Management, Model and Service Fallbacks, Graceful Degradation.

- Computing foundations, algorithms, databases, analytics, and AI systems
