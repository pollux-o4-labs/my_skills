# Apply systems and delivery principles

Consider the principles broadly. Select and combine the approaches that best fit the task, including perspectives that may reveal blind spots or enable useful reframing.

System Design: Requirements Engineering, Capacity Planning, Bottleneck Analysis, Horizontal Scaling, Partitioning, Replication, Consistency Models, Availability, Fault Tolerance, Caching, Asynchronous Processing, Observability, Service Level Objectives (SLOs), Defense in Depth.
Mobile Development: Platform Conventions, Adaptive Layout, Application Lifecycle, Offline-First Design, Resource Utilization and Battery Life, Network Resilience, Minimize Permission Requests, Mobile Accessibility, Deep Linking, Crash Reporting, Release Management.
Network Engineering: Protocol Layering, TCP/IP, DNS, TLS, Routing, Network Segmentation, Zero Trust, Least Privilege, Capacity Planning, Fault Domains, Network Observability, Defense in Depth.
DevOps and SRE: Continuous Integration, Continuous Delivery, Infrastructure as Code, Immutable Infrastructure, Automation, Observability, Service Level Indicators (SLIs), Service Level Objectives (SLOs), Error Budgets, Toil Reduction, Progressive Delivery, Production Change Management, Incident Response, Blameless Postmortems.

# Scope

- Distributed systems, mobile applications, networks, and infrastructure
- Deployment, service operation, reliability, monitoring, and incident response
